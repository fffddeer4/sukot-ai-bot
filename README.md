## ✨ امکانات

### سرویس جدید «کوآرنا» — آرنای مدل‌های جهانی با یک کلید (1.16.0)
- 🏟 **سرویس جدید «کوآرنا»** (`coarena.ai`) با کلید آمادهٔ شخصی — **هر ۱۸ مدلِ فعال با درخواست واقعی فارسی تست شد ✓** (Claude Sonnet/Opus/Fable/Haiku · Gemini 4/3.8 · Grok 4.7 · Kimi K3 · Qwen3.8 · GLM 5.3 · DeepSeek · MiniMax · MiMo · Hy4)
- 👁 **همهٔ مدل‌های کوآرنا عکس می‌بینند** (بینایی واقعی — تست‌شده با تصویر) + استدلال + ابزار؛ پنجرهٔ ۱۲۸K و خروجی تا ۱۶K توکن — همه رایگان
- 🐛 **رفع باگ ریشه‌ای استریم**: terminator استاندارد `data: [DONE]` قبلاً نادیده گرفته می‌شد و اگر سرور بعد از پایانِ پاسخ اتصال را سریع نبند (مثل کوآرنا)، پاسخ تا ابد «در حال نوشتن» می‌ماند — حالا استریم با [DONE] فوراً تمام می‌شود (روی همهٔ سرویس‌ها و هر سه محیط موبایل/کامپیوتر/وب)
- 🐛 **رفع خواندن خطاهای فرمت ساده**: خطاهایی با پیام در سطح بالای JSON (مثل کوآرنا) قبلاً ناشناخته می‌ماندند — حالا دسته‌بندی و پیام فارسی درست دارند
- 🚦 **مدیریت خودکار سقف ۲ درخواستِ همزمان**: اگر کوآرنا شلوغ باشد، سوکوت خودکار با فری‌مدل و بعد پولینیشن جواب می‌دهد + در «تست اتصال» یک بار با وقفهٔ کوتاه دوباره تلاش می‌کند
- 🎴 **جزئیات کامل هر مدل در انتخاب‌گر**: سازنده، قابلیت‌ها، پنجره، خروجی و «رایگان» + ۴ گروه لمسی + دکمهٔ پیشنهادی برای Claude Sonnet 5.5 (گفتگو) و Gemini 3.8 Flash (عکس)
- 🔧 باکس مخصوص «API کوآرنا» در تنظیمات (آدرس + کلید قابل تغییر) + سهمِ فکرِ مدل‌های استدلالیِ کوآرنا خودکار بالا می‌رود تا جواب نصفه نماند + مدل‌های هم‌نام بین فری‌مدل و کوآرنا با هم قاطی نمی‌شوند

### پنل «پارامترهای هوش مصنویی» — کنترل فکر و توکنِ هر مدل (1.15.0)
- 🎛 **دکمهٔ جدید «پارامترها» در نوار بالا**: پنل اختصاصی مثل پنل Parameters فری‌مدل — **خلاقیت (Temperature)**، **سهم فکر و توکن خروجی (Max output tokens تا ۳۲K)**، **تنوع خروجی (Top P)** و **دستور اختصاصی مدل (System prompt)**
- 🧠 **«هر مغز، تنظیمِ خودش»**: برای هر مدل می‌توانی پارامتر جدا بدهی (مثلاً GLM خلاقیت ۰٫۷ و فکرِ زیاد؛ DeepSeek خلاقیت ۰٫۳ و جواب کوتاه) یا یک تنظیم سراسری برای همهٔ مدل‌ها بگذاری
- ⚡ پارامترها **واقعاً در بدنهٔ درخواست همهٔ سرویس‌ها** (دال · فری‌مدل · کلادفلر · پولینیشن · Groq · Gemini و…) اعمال می‌شوند — نه فقط ظاهر؛ مدل‌هایی که پارامتر را قبول نمی‌کنند خودکار بدون آن صدا زده می‌شوند
- 🏷 چیپ نارنجی کنار پاسخ وقتی پارامتری غیرپیش‌فرض است + چیپ‌های سریع توکن (۱K / ۴K / ۱۶K / ۳۲K)
- 💾 ماندگاری کامل تنظیمات (هر مدل جدا در حافظه) + رابط لمسیِ موبایل و دسکتاپ — ۳۰ تست Playwright پاس

### فری‌مدل + گفتگوی صوتی زنده + صدای ابری + رفع باگ GLM (1.14.0)
- 🌍 **سرویس جدید «فری‌مدل»** (`freemodel.in`) با کلید آمادهٔ شخصی — فقط **۲۹ مدلِ «فعال» کاتالوگ رسمی** اضافه شده (GPT-6/5.6 · Claude Opus 5.5/5 · Gemini 3.7 · Grok 4.6 · Kimi K3 · DeepSeek V4.1 و…)؛ ۱۷ مدلِ در حال تعمیر حذف شده‌اند
- 🎴 **جزئیات کامل هر مدل در انتخاب‌گر**: سازنده، قابلیت‌ها (استدلال/بینایی/ابزار)، پنجرهٔ کانال‌متن (تا ۱M) و قیمت رسمی هر ۱M توکن + گروه‌بندی ۵گانه
- 🧩 **چیپ «با مغز …» زیر هر پاسخ** — مدلِ واقعیِ پاسخ‌دهنده همیشه دیده می‌شود (رفع شکِ «مدل عوض نمی‌شود»)
- 🐛 **رفع باگ ریشه‌ای «مدل روی GLM ماند»**: باگ از حذف‌شدن پرچم داخلی `dahlMigrated` هنگام ذخیرهٔ تنظیمات بود که باعث می‌شد در اجرای بعدی، مهاجرت قدیمی مدل را به زور به GLM برگرداند — حالا ادغام تنظیمات پرچم‌ها را حفظ می‌کند + انتخاب مدل سراسری قفل شد + دو تست رگرسیون اختصاصی
- 🎙 **گفتگوی صوتی زنده مثل ChatGPT**: دکمهٔ میکروفون کنار نوشتار ← صفحهٔ تمام‌عکس با **دایرهٔ بزرگِ رنگین** (سبز = گوش می‌دهم، بنفشِ چرخان = فکر می‌کنم، رنگین‌چرخان = حرف می‌زنم) + تشخیص گفتار فارسی/انگلیسی/عربی/ترکی + ارسال خودکار بعد از سکوت + چرخهٔ گفت‌وشنید + زیرنویس زنده
- 🎨 **۶ تم رنگی برای دایره** (بنفش/آبی/سبز/نارنجی/صورتی/رنگین‌کمان) — در حالت رنگین‌کمان هر حالت رنگ خودش را دارد
- 🔊 **بخش مخصوص «API صدای ابری»**: آدرس، کلید، مدل، صدا و سرعت همه قابل تنظیم + دکمهٔ تست صدا + دو حالت API (tts.ai آسنکرون / سازگار با OpenAI)
- 🚫 **صدای پیش‌فرض سامسونگ/دستگاه کاملاً حذف شد** — صدا فقط با API ابری (پیش‌فرض: صدای فارسی امیر از tts.ai)؛ بدون نیاز به نصب هیچ صدایی روی گوشی
- ⚡ **سرعت**: نظرسنجی سریع صدا (چک‌های ۰٫۷ ثانیه‌ای) + تکهٔ اولِ کوچک‌تر + پیش‌واکشی تکهٔ بعد + شمارندهٔ ثانیه روی «در حال نوشتن»
- 🛟 زنجیرهٔ فالبک جدید: **فری‌مدل ← دال ← پولینیشن** (با خطای کلید/موجودی/اتصال خودکار سوییچ می‌کند)

### رفع ارور «محدودیت درخواست» دال — فالبک خودکار مغز شلوغ (1.10.1)
- 🚦 **وقتی مغز GLM 5.3 Flash روی پلن رایگان لحظه‌ای شلوغ باشد** (خطای `model_concurrency`)، سوکوت دیگر ارور نمی‌دهد — **خودکار با مغزِ آزادِ همان سرویس** (MiniMax M2.7 یا DeepSeek V4 Flash) ادامه می‌دهد و پایین جواب صادقانه می‌نویسد: «مغز GLM همین لحظه شلوغ بود؛ این پاسخ با مغز جایگزین … داده شد»
- 🛟 اگر هر ۳ مغز دال همزمان شلوغ باشند، خودکار به **سرویس رایگان پولینیشن** سوییچ می‌کند — دیگر هیچ‌وقت پیام بی‌جواب نمی‌ماند
- 💡 چراغ وضعیت زندهٔ بالای صفحه و دکمهٔ «تست اتصال» هم با مغز جایگزین سبز می‌شوند و نام مغزی که واقعاً جواب داده را نشان می‌دهند
- ✅ شبیه‌سازی کامل هر دو سناریو (GLM شلوغ → MiniMax جواب داد / هر ۳ شلوغ → پولینیشن جواب داد) + هر دو بستهٔ قبلی تست رابط — همه پاس

### حذف TokenRouter/OpenRouter + رفع باگ «فقط ۳ مدل» کلادفلر (1.10.0)
- 🧹 **دو سرویس TokenRouter و OpenRouter به‌کامل از فهرست پلن‌ها حذف شدند** (به خواست کاربر) — کسی که روی آن‌ها بود خودکار به «دال» با کلید آماده منتقل می‌شود و چیزی از دست نمی‌دهد
- 🐛 **رفع باگ مهم**: قبلاً وقتی پلن را روی کلادفلر می‌گذاشتی، انتخاب‌گرِ مدل هنوز فقط ۳ مدل دال را نشان می‌داد — حالا تغییر پلن **همان لحظه ذخیره و اعمال می‌شود** و انتخاب‌گرِ مدلِ همان پلن را می‌آورد (کلادفلر = **هر ۲۷ مدل** با تیترِ گروه‌بندی: غول‌ها / عمومی / کد / استدلال / بینایی / سبک)
- 🎨 رفع باگ ماندگاری تم: تم‌های زمردی/غروب/نیمه‌شب بعد از بستن و بازکردن برنامه هم می‌مانند (قبلاً به شبِ بنفش برمی‌گشت)
- ✅ هر دو بستهٔ تست رابط (v1.9.0 + v1.10.0 — ۴۶ بررسی) کامل پاس شد

### سرویس جدید «دال» — GLM 5.3 Flash با کلید آماده (1.8.0)
- ⚡ **بدون هیچ تنظیمی کار می‌کند**: اپ با سرویس جدید **دال** (`inference.dahl.global`) از قبل پیکربندی شده — نصب کن و همان اولین پیام جواب بگیر
- 🧠 **مغز اصلی: GLM 5.3 Flash** — مدل استدلالیِ سریع با کانتکست ۱ میلیون توکن؛ هر ۳ مدل دال (GLM 5.3 Flash · MiniMax M2.7 · DeepSeek V4 Flash) با درخواست واقعی تست و تأیید شدند (چت + استریم زنده + پاسخ فارسی)
- 💭 **هوش استدلالی کامل**: مرحلهٔ فکر کردنِ مدل به‌شکل «دارم عمیق فکر می‌کنم…» نمایش داده می‌شود و فقط جوابِ تمیز می‌ماند — هم فیلد جداِ `reasoning` و هم تگ‌های `<think>` داخل متن پشتیبانی می‌شود
- 🛟 **جبران خودکار سهمِ فکر**: اگر فکرِ مدل کل سهم توکن را خورد و جوابی نیامد، سوکوت خودکار با سهم بزرگ‌تر ادامه می‌دهد — مدل‌های استدلالی هیچ‌وقت بی‌جواب نمی‌مانند
- 🔑 باکس مخصوص «API دال» در تنظیمات (آدرس + کلید، قابل تغییر) + بقیهٔ سرویس‌ها هم سر جای خودشان
- 📷 این سرویس فعلاً عکس نمی‌بیند؛ اگر عکس بفرستی متن پیامت حفظ می‌شود و با نکتهٔ فارسی مطلع می‌شوی (برای دیدن عکس، کلادفلر را انتخاب کن)

### استودیوی عکس + خطایابی بازی + مدیریت API + ۸ بخش تنظیمات (جدید در 1.6.0)
- 🖼 **استودیوی حرفه‌ای ساخت عکس**: توضیح فارسی یا انگلیسی + ۸ سبک (واقع‌گرایانه، انیمه، دیجیتال آرت، آبرنگ، پیکسل‌آرت، سه‌بعدی، آرت بازی) + گالری «ساخته‌های اخیر» + ذخیره + **پیوست تصویر به گفتگو** تا درباره‌اش سؤال کنی — با API واقعی (Flux کلادفلر + پولینیشن رایگان؛ بدون هیچ تصویر ساختگی)

- 🗂 **تنظیمات ۸ بخشی**: عمومی · ظاهر و تم · مدل هوش · مدیریت API · ساخت عکس · بازی‌سازی · امنیت و حریم خصوصی · درباره — با کارت‌های مرتب و سازگار با موبایل
- 🎨 **۳ تم واقعی**: شبِ بنفش، اقیانوس آبی، روشن + **اندازهٔ متن پیام‌ها** + حالت کم‌انیمیشن
- 🛡 **حریم خصوصی**: پاک‌کردن گفتگوها / حافظه / همهٔ داده‌ها با تأیید دومرحله‌ای — کلیدها فقط روی دستگاه خودت می‌مانند

### ساخت عکس + استودیوی بازی + سرویس‌های رایگان بدون کارت (1.5.0)

- 🎮 **استودیوی بازی‌سازی + اجرای زنده**: دستیار تخصصی «بازی‌سازی» بازی کامل HTML5 می‌سازد و روی هر بلوک کد دکمهٔ **«اجرای بازی»** می‌آید — بازی همان‌جا داخل اپ در محیط ایزتهٔ امن (sandbox) اجرا می‌شود؛ تمام‌صفحه هم دارد
- 🌍 **سرویس‌های رایگانِ بدون کارت بانکی** (در تنظیمات، تب «اتصال»): **پولینیشن** (بدون حتی ثبت‌نام)، **Groq** (فقط ایمیل — سریع‌ترین سرور دنیا)، **Google Gemini** (کلید رایگان از AI Studio) + OpenRouter و Cloudflare
- 🧩 **API خارجی دلخواه**: بخش مخصوص در تنظیمات — هر سرویس سازگار با OpenAI (Ollama، LM Studio، پروکسی شخصی…) را با آدرس + کلید + مدل وصل کن
- 🗂 **تنظیمات ۵ تبه شد**: اتصال و API خارجی · ساخت عکس · جستجو و ابزار · صدا · پاسخ و شخصیت — دیگر شلوغ نیست
- ✍️ املای درست نام: «**سوکوت**» در همه‌جا اصلاح شد

## 🌐 نسخهٔ وب (اختیاری)

مرورگرها به‌خاطر سیاست CORS نمی‌توانند مستقیم به `api.cloudflare.com` وصل شوند. نسخهٔ اندروید و ویندوز این مشکل را با پل بومی (Native Bridge) دور می‌زنند. اگر نسخهٔ وب را می‌خواهی:

1. در کلادفلر: **Workers & Pages → Create → Worker**
2. محتوای فایل [`worker/worker.js`](worker/worker.js) را داخلش Paste کن و Deploy بزن
3. در تنظیمات ربات، «آدرس API» را بگذار: `https://<your-worker>.workers.dev/cf/<ACCOUNT_ID>`
